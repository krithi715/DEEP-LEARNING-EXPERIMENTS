# Transformer-Based LLM Chatbot Using Qwen2.5

## Project Overview

This project implements an interactive AI chatbot using a pre-trained Large Language Model (LLM). It uses the Qwen2.5-0.5B-Instruct model to understand user prompts and generate meaningful conversational responses.

The chatbot is developed using Python, PyTorch and Hugging Face Transformers in Google Colab.

## Objectives

- Understand the working of pre-trained Transformer models.
- Implement text generation using an LLM.
- Develop a chatbot that accepts user prompts.
- Maintain conversation history for contextual responses.
- Experiment with temperature and maximum token settings.
- Create an interactive chatbot interface using Gradio.

## Technologies Used

- Python
- Google Colab
- PyTorch
- Hugging Face Transformers
- Qwen2.5-0.5B-Instruct
- Gradio

## Model Information

| Parameter | Details |
|---|---|
| Model Name | Qwen2.5-0.5B-Instruct |
| Architecture | Transformer |
| Model Type | Causal Language Model |
| Framework | PyTorch |
| Tokenizer | AutoTokenizer |

## Key Features

1. **Pre-trained Language Model:** Uses Qwen2.5-0.5B-Instruct for generating responses.
2. **Text Generation:** Generates responses based on user prompts.
3. **Conversation History:** Maintains previous interactions to provide contextual responses.
4. **Temperature Control:** Adjusts the randomness and creativity of generated responses.
5. **Maximum Token Control:** Controls the maximum length of generated responses.
6. **Interactive Chatbot:** Provides a simple conversational interface using Gradio.

## Implementation Steps

1. Install the required Python libraries.
2. Import the necessary libraries.
3. Load the pre-trained model and tokenizer.
4. Tokenize user prompts.
5. Generate responses using the model.
6. Implement conversation history.
7. Experiment with different temperature values.
8. Create an interactive chatbot using Gradio.

## Execution

The project is implemented in Google Colab.

1. Open the notebook in Google Colab.
2. Run the installation and import cells.
3. Load the Qwen2.5-0.5B-Instruct model.
4. Execute the text generation function.
5. Run the chatbot interface.
6. Enter questions and interact with the chatbot.

## Limitations

- Responses may sometimes contain inaccurate information.
- The model may not provide detailed answers to complex questions.
- Response quality depends on the input prompt.
- The model has limited knowledge compared with larger language models.

## Conclusion

This project demonstrates the implementation of a conversational AI chatbot using a pre-trained Transformer-based language model. It provides practical experience in model loading, tokenization, text generation, conversation history management and interactive chatbot development.
