# Generative Adversarial Network (GAN) – MNIST Image Generation

## AIM
To implement and train a Generative Adversarial Network (GAN) to generate synthetic handwritten digit images using a Generator and Discriminator in an adversarial learning framework.

## TECHNOLOGIES USED
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Google Colab
- GitHub

## DATASET
**MNIST Handwritten Digit Dataset**

- 60,000 training images
- 10,000 testing images
- Image dimensions: 28 × 28 pixels
- Grayscale images containing handwritten digits (0–9)
- Pixel values normalized from [-1, 1]

## OBJECTIVES
- Understand GAN architecture and working.
- Build Generator and Discriminator models.
- Generate random noise vectors.
- Train both networks using adversarial learning.
- Monitor Generator and Discriminator losses.
- Generate and visualize synthetic images.
- Compare original and generated images.

## GAN ARCHITECTURE

The GAN consists of two neural networks:

### 1. Generator
- Takes a 100-dimensional random noise vector as input.
- Uses Dense and Conv2DTranspose layers.
- Generates synthetic images of size 28 × 28 × 1.
- Uses Tanh activation in the output layer.

### 2. Discriminator
- Takes real and generated images as input.
- Uses Conv2D, LeakyReLU, Flatten and Dense layers.
- Classifies images as real or fake.
- Uses Sigmoid activation in the output layer.
